# Dsquares Evo: Android downloads

**Dsquares Evo** is an English-learning companion for Dsquares employees: short daily practice that adapts to you, real workplace situations and clear progress.

This repository only hosts the **Android app downloads**. The app's source code is not published here.

## Download (latest version)

- This link always points to the newest release. No GitHub account is needed.
- Every version, with its release notes and SHA-256 checksums, is listed under [Releases](https://github.com/ahmedsayed-ops/dsquares-evo-releases/releases).

## Requirements

Android 7.0 or newer, on a 64-bit ARM phone (practically all phones from 2017 onward).

## Install

1. Open the download link on your Android phone.
2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps.
3. Google Play Protect may warn about an app from an unknown developer. Dsquares Evo is not on Google Play, so this is expected for apps downloaded from this page.

To check the file, compare its SHA-256 with `SHA256SUMS.txt` in the release. On Windows: `certutil -hashfile dsquares-evo.apk SHA256`.

## Updating

Install a new version over the old one and **do not uninstall first**. Your progress is stored only on your phone, and uninstalling deletes it.

If you installed an early private **test** build (0.2.0 to 0.5.0), uninstall it before installing 1.0.0. This deletes that test build's progress.

## Privacy

The app has no account and sends no learning data anywhere. Progress stays on your phone.
